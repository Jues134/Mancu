这个目录存放"你的东西"：所有历史记录、上传的素材、生成的结果。

  studio.db   全部历史对话与运行记录（SQLite 数据库）
  uploads\    你上传的图片 / 音频 / 视频
  assets\     生成的参考图、分镜图等
  videos\     生成的视频与成片
  backups\    在界面上删除内容时留下的备份

首次启动时程序会自动创建这些内容，解压后这里是空的属于正常现象。

备份：先运行“stop.cmd”停止程序，再把整个 userdata 目录复制到安全位置。
恢复：停止程序，用备份覆盖本目录，再启动。
注意：界面上的删除是硬删除，会连同生成的文件一起移除，重要作品请先备份。

★ 本目录可能包含你的素材和作品，属于个人数据。分享程序时请勿把本目录发给别人；
  发布包本身不包含此目录里的任何内容。
