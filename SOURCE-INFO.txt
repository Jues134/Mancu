漫簇 Mancu — 源码版（Windows 64 位）

这是不带 Python 运行环境和第三方依赖的源码发行包。

使用前请先阅读根目录 README.md。详细安装方法见 docs\INSTALL.md，完整部署、
配置、备份和故障排查方法见 DEPLOY.md。

最快启动方式：
1. 安装 64 位 Python 3.11 或更高版本。
2. 解压完整 ZIP。
3. 双击“start.cmd”。

start.ps1 会建立项目专用的 .venv，检查依赖完整性，缺少时联网下载，然后启动项目。
下载 Python 依赖时优先使用清华、阿里云、腾讯国内源，全部失败后才尝试官方源；
重新构建前端时优先使用 npmmirror 和腾讯源。
项目已经包含构建好的网页文件；普通使用不需要安装 Node.js。

首次使用时请在项目设置页面填写你自己的模型供应商和 API Key。
